대통령기록관 모의 포털

실행: index.html을 브라우저에서 열거나 이 폴더를 정적 웹 서버로 제공합니다.
별도 빌드나 패키지 설치 없이 실행합니다. 시작 화면에서 관리자 실습 메뉴로 이동하세요.
HTTPS 또는 localhost에서 Web Crypto SHA-256을 사용합니다.
Web Crypto가 없는 환경에서는 정규화한 문자열을 직접 비교합니다.

실습 순서
1. 관리자 실습 → 실습 권한 활성화
2. 원문 변조 실행 또는 메타데이터 변조 실행 (수동 편집 가능)
3. 진본성 검증실 → 전체 기록 검증 → 불일치 확인
4. 해당 기록물 복구 → 기준본 일치 및 감사 이력 확인
5. 감사 이력 JSON 내보내기

실제 대통령기록관과 무관하며 모든 기록은 가상 자료입니다.
기준본은 portal.js에 포함된 시험 데이터입니다.
게시본과 감사 이력은 브라우저 localStorage에 저장합니다.
실습 권한은 인증 기능이 아닙니다. 재접속 시 비활성화됩니다.
검증 결과는 새로고침 후 재검증해야 합니다. 감사 이력은 보존됩니다.
감사 로그는 보호된 저장소가 아니며 변경 방지 기능이 없습니다.
전자서명, 공인 타임스탬프, 보존 서버, 사용자 인증 및 권한 통제는 구현하지 않았습니다.
실제 운영 환경의 진본성 보장 기능을 대체하지 않습니다.
폰트는 Google Fonts를 사용하며 오프라인에서는 시스템 폰트로 표시됩니다.
